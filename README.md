# U.S. Analytics Job Market Intelligence

An end-to-end analytics project analyzing current U.S. analytics job postings using Python, SQL, BigQuery, and Tableau.

## Project Goal

This project analyzes the U.S. analytics job market to understand:

- Where analytics jobs are concentrated
- Which skills employers demand most
- How salaries vary by role, location, and skills
- What the entry-level analytics job market looks like

## Roles Analyzed

- Data Analyst
- Business Analyst
- Product Analyst

## Tech Stack

- Python
- Pandas
- REST API
- SQL
- BigQuery
- Tableau

## Project Workflow

Data API → Python → Data Cleaning → BigQuery → SQL → Tableau
